PROJECT 01 / 2024.02

Eve

進級制作展で制作した、Eveのファンアートサイトです。好きなアーティストの世界観をWebで表現することに取り組み、独創力賞をいただきました。

Visit site ↗
01

世界観を読み取るところから

本人に直接意図を聞くことはできないため、公式サイトやライブ、グッズから、大切にしている雰囲気や表現を読み取るところから始めました。そこで感じたものを、画面の色や構成として形にすることが難しかった点です。

02

世界観を邪魔しない表現

配色や構成は公式サイトを参考にし、Eveらしい雰囲気から離れないことを意識しました。そのうえで、ライブなどを通して自分が感じた印象も取り入れ、元の世界観を邪魔しない範囲で表現を加えました。

PROJECT 02 / 2025.06

Lumos & Musk

学校のECサイト制作課題で取り組んだ、架空のフレグランスブランドです。秋と冬をテーマに、香りの体験から購入につながるサイトを考えました。

Visit site ↗
01

サイトより先に、ブランドを考える

まずはECサイトに必要な機能や役割を理解するところから始め、実際のサイトを調べながら、商品に興味を持ってもらう導線を考えました。そこから架空のブランドの事業を想像し、「香りをまとった空間を体験する」というコンセプトを組み立てました。

02

体験をきっかけに、香りを選ぶ

空間体験を予約し、そこで気に入った香りを購入する流れと、香りの診断からおすすめの商品に出会う流れを用意しました。商品を並べるだけでなく、体験を通して自分に合う香りを選び、購入へ進める導線を意識しています。

PROJECT 03 / 2025.12

Beauty Portfolio

美容学生の友人から依頼を受けたポートフォリオサイトです。作品の魅力と依頼者らしい雰囲気が伝わり、仕事の相談にもつながる構成を目指しました。

Visit site ↗
01

異なる分野の魅力を、どう伝えるか

ポートフォリオ制作の経験が少ないなか、自分とは異なる分野の作品をどう見せれば魅力が伝わるのかが課題でした。ポートフォリオやサロンのサイトを調べ、作品を見た人が依頼へ進みやすい構成も検討しました。

02

画面を見ながら、希望をすり合わせる

依頼者はWeb制作やFigmaに馴染みがなかったため、まず自分でワイヤーフレームを作り、完成形を想像してもらいました。「何を見せたいか」「どこを変えたいか」を画面を見ながら繰り返し確認し、依頼者の雰囲気と作品の見やすさを両立できるよう構成を調整しました。

PROJECT 04 / 2026.03 · IN PROGRESS

Sukima Keshiki

グループで制作したバイクコミュニティアプリです。UI/UX設計とフロントエンド開発を担当し、最後まで制作を進めてコンテストに応募しました。

01

メンバーの意見を、画面に落とし込む

Miroで「どんな導線にしたいか」「何を載せたいか」といったメンバーの意見を整理しました。必要なコンテンツや操作の流れを検討し、Figmaでの画面設計からフロントエンドの実装まで取り組みました。

02

画面が具体化した段階での共有

振り返ると、情報設計の段階だけでなく、Figmaで画面が具体化した段階でもメンバーと導線を確認し、認識を揃える必要がありました。コンテストの結果は目標に届きませんでしたが、制作をやり切るなかで、設計途中の共有と確認の大切さを学びました。

PROJECT 05 / 2026.04

Eve Player

Reactを使ったWebアプリ制作課題で取り組んだ音楽プレイヤーです。1年次に制作したEveのファンアートサイトに、新しい音楽体験を加えたいと考えました。

Visit site ↗
01

レコードを選んで聴く感覚を

デジタルの画面に、アナログのレコードを選んで聴く感覚を取り入れたいと考えました。楽曲のジャケットも活かしたかったため、ジャケットからレコードを取り出すイメージが、音楽とビジュアルを楽しむ体験に合うと感じました。

02

聴く前の、選ぶ時間も楽しむ

ReactとAPIを使い、レコード型のプレイヤーやジャケットが並ぶコレクション画面を制作しました。音楽を聴くだけでなく、ジャケットを眺めながら曲を探す時間も楽しめるアプリを目指しました。

PROJECT 06 / 2026.09 · IN PROGRESS

Hacolio

趣味のレトロゲームやグッズを管理し、友人とも交流できる場所がほしいと考えて始めた個人開発です。持ち物と保管場所を管理するWebアプリとして、現在も開発を続けています。

Figmaは公開用にまとめた閲覧用データです。開発用ファイルとは異なります。

View in Figma ↗
01

自分が日常で使うものを作る

当初は管理と交流ができるWebサイトを想定していました。授業でReactに触れ、その自由度を知ったことをきっかけに、いつでも使えるWebアプリとして作ることにしました。自分の収集趣味から生まれたアイデアを、日々使える形にすることが出発点です。

02

意見をもらい、機能と画面を絞る

最初はほしい機能を幅広く盛り込もうとしていましたが、友人や先生から機能の多さやアプリの特徴について意見をもらい、中心になる機能を考え直しました。UIも基本画面ができた段階で複数の友人に見てもらい、感想や改善の意見を取り入れながら調整しています。
